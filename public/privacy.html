PRIVACIDAD

QUADRIFT es un videojuego multijugador experimental. Mientras juegas, tu apodo, la posición de tus piezas y las puntuaciones se comparten con otros jugadores conectados a la misma arena. Los datos de partida se mantienen en la memoria del servidor y no se almacenan en una base de datos en esta versión.

El proveedor de alojamiento (Render) procesa datos de conexión necesarios para entregar el servicio, como direcciones IP y registros técnicos. Este proyecto no dispone de cuentas de usuario ni requiere correo electrónico.

La integración de Google AdSense se entrega desactivada. Si se habilita en el futuro, esta política deberá completarse con el nombre del responsable, medios de contacto, uso de cookies, consentimiento y enlaces a las prácticas de privacidad de Google según las regiones aplicables.

Antes de publicar comercialmente, sustituye este aviso técnico por una política específica de tu organización e incorpora un canal de contacto.
